Abstract (Draft)

Vision-Language Models (VLMs) perform well on general visual reasoning tasks but remain limited in domain-specific settings where the correct interpretation depends on contextual information beyond the image itself. This is particularly important in agriculture, where geographic location, seasonality, crop identity, and regional growing conditions can substantially affect both diagnosis and management recommendations. Although retrieval-augmented generation (RAG) can provide external knowledge, conventional static retrieval pipelines do not explicitly reason about such context or adapt when the available evidence is insufficient.

We present MIRAGE-RAG, an adaptive, metadata-aware retrieval framework for contextual agricultural reasoning. The framework incorporates geographic and temporal metadata directly into retrieval through progressive filtering, which evaluates increasingly relaxed metadata scopes while preserving semantic relevance. It further combines crop-aware query enrichment, hardiness-zone-based geographic grounding, and a curated agricultural knowledge base with confidence-aware retrieval. When retrieved evidence is insufficient, the system can selectively search trusted domain sources, ingest newly acquired evidence into a run-scoped knowledge store, and reuse that information for subsequent queries.

We evaluate MIRAGE-RAG through controlled ablations that isolate the contributions of static retrieval, contextual enrichment, progressive metadata filtering, confidence estimation, domain-constrained web search, and adaptive knowledge ingestion across multiple vision-language models. This decomposition allows us to study not only whether retrieval improves agricultural reasoning, but which mechanisms make adaptive RAG effective and under what conditions. Our findings show that robust contextual reasoning depends not merely on providing metadata to the model, but on using that metadata to control how external knowledge is retrieved, evaluated, and expanded, enabling stronger domain grounding without model retraining.
