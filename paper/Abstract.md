Abstract

MIRAGE-CARMA: Context-Adaptive Retrieval with Metadata Awareness for Multimodal Reasoning
Vision-Language Models (VLMs) perform well on general visual reasoning tasks but remain limited in domain-specific settings where the correct interpretation depends on contextual information beyond the image itself. This is particularly important in agriculture, where geographic location, seasonality, crop identity, and regional growing conditions can substantially affect both diagnosis and management recommendations. Although retrieval-augmented generation (RAG) can provide external knowledge, conventional static retrieval pipelines do not explicitly reason about such context or adapt when the available evidence is insufficient.

We present MIRAGE-CARMA, an adaptive, metadata-aware retrieval framework for contextual agricultural reasoning. The framework incorporates geographic and temporal metadata directly into retrieval by evaluating multiple retrieval strategies, ranging from combinations of location-, time-, and document-specific constraints to progressively broader metadata filters and finally unrestricted semantic retrieval. We refer to this process as progressive metadata filtering. It then selects the strategy that yields the strongest relevant evidence. It further combines crop-aware query enrichment, location-aware grounding using agro-climatic zones, and a curated agricultural knowledge base from reliable government, university and extension sources with confidence-aware retrieval. When retrieved evidence is insufficient, the system can selectively search trusted domain sources, ingest newly acquired evidence into a knowledge store, and reuse that information for subsequent queries.

We evaluate MIRAGE-CARMA through controlled ablations that isolate the contributions of static retrieval, contextual enrichment, progressive metadata filtering, confidence estimation, domain-constrained web search, and adaptive knowledge ingestion across multiple vision-language models. This decomposition allows us to study not only whether retrieval improves agricultural reasoning, but which mechanisms make adaptive RAG effective and under what conditions. Our evaluation investigates whether contextual metadata is most effective when used not simply as additional model input, but as a signal for controlling how external knowledge is retrieved, evaluated, and expanded. The goal is to improve domain grounding without requiring model retraining.
