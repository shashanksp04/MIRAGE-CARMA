# Introduction

The MIRAGE benchmark frames agricultural assistance as multimodal, expert-guided question answering: a record can combine a natural-language question, image context, an expert response, a task category, and structured metadata [@dongre2025mirage]. In this setting, an image may support identification while the user's question asks for management guidance that also depends on a crop, place, or time. The system must therefore connect visible evidence with external information relevant to the question rather than treat the task as image classification alone.

Multimodal language models provide an interface for jointly interpreting images and instructions [@liu2023llava]. Retrieval-augmented generation (RAG) complements this capability with explicit non-parametric memory, allowing generation to condition on retrieved passages and making the knowledge source easier to update or inspect than parametric knowledge alone [@lewis2020rag]. The static semantic-retrieval baseline considered in this work nevertheless has two practical constraints. Its collection cannot contain sources added after the collection was built, and similarity ranking alone does not explicitly represent whether a passage matches the structured context available for a question. These constraints motivate two research questions: how should metadata-constrained retrieval strategies be evaluated without making metadata mandatory, and when should the system seek evidence beyond a curated collection?

We present *MIRAGE-CARMA* (Context-Adaptive Retrieval with Metadata Awareness for Multimodal Reasoning), an adaptive, metadata-aware retrieval framework for contextual agricultural reasoning. It is distinct from both the agricultural MIRAGE benchmark [@dongre2025mirage] and the e-commerce retrieval-and-generation system named MIRAGE introduced by Sahay et al. [@sahay2026ecommercemirage]. MIRAGE-CARMA addresses the research questions above through metadata-aware retrieval and optional online evidence acquisition. The system derives a USDA plant hardiness zone from county-state metadata when possible, with a state-modal fallback, and uses that zone as a geographic retrieval constraint. A hardiness zone is a climate-derived proxy based on average annual extreme minimum winter temperature [@usda2023phzm]; it should not be interpreted as county-level regulatory, pest-pressure, or extension-jurisdiction matching.

When progressive metadata filtering is enabled, the retriever evaluates multiple eligible retrieval strategies that combine hardiness-zone, `month_year`, and `title` constraints at varying levels of specificity, together with unrestricted semantic retrieval. It then selects the strategy that yields the strongest relevant evidence under a common scoring rule. Semantic-only retrieval is therefore always available as a candidate rather than appearing only after metadata-constrained retrieval fails. Missing optional metadata removes only the strategies that require those fields rather than preventing retrieval altogether. The `month_year` field is used as retrieval metadata but can have mixed provenance; the Methodology describes how it is populated and the limitations of its interpretation.

MIRAGE-CARMA separates textual evidence acquisition from multimodal response generation. A text-based evidence controller receives the effective question and available location metadata, while the downstream answer model receives the question, retrieved passages, and one or more images. An optional enrichment step may insert an implicit crop name from a state-specific allowlist, subject to an insertion-only validation rule. This decomposition keeps the evidence pathway independently configurable and assigns the controller the role of acquiring and returning supporting passages rather than composing the final multimodal answer.

At inference time, retrieval spans a read-only curated base collection and a mutable collection scoped to the current run. A fixed confidence heuristic combines mean retrieval similarity, hit count, score dispersion, and the metadata strategy selected by retrieval; it is a routing score rather than a calibrated probability of correctness. When the heuristic assigns low confidence, a natural-language agent instruction directs the controller to form search terms, search the web, optionally restrict the search to location-linked academic domains, ingest acquired pages into the runtime collection, and retrieve again. The score computation is deterministic, whereas compliance with this multi-step branch is governed by the tool-using model and its prompt rather than by a deterministic Python state machine. The runtime collection permits newly acquired evidence to be reused by later items in the same run without modifying the curated base. Adaptive retrieval has also been studied as an alternative to indiscriminately retrieving a fixed number of passages [@asai2024selfrag]; our focus is the concrete combination of structured agricultural metadata, confidence-aware evidence acquisition, isolated online ingestion, and multimodal answer generation.

We plan to evaluate this architecture on the MIRAGE agricultural benchmark [@dongre2025mirage]. The checked-in benchmark records contain one to three images and include geographic metadata when available. The planned ablation design compares direct multimodal generation with RAG configurations that vary curated-base access, crop enrichment, progressive metadata filtering, confidence assessment, web search, domain filtering, and runtime knowledge ingestion. Several comparisons change bundles of mechanisms and will be interpreted as such. The authoritative final condition matrix, run manifests, shared model configuration, benchmark subset, and other executed controls require verification before empirical comparisons are reported.

This work makes four implementation and study-design contributions:

1. It instantiates a two-stage pipeline for the MIRAGE setting in which textual evidence acquisition is configurable independently of image-conditioned answer generation.
2. It introduces progressive metadata filtering, in which multiple retrieval strategies combine a derived USDA plant hardiness zone with optional controller-supplied `month_year` and `title` constraints and are evaluated alongside unrestricted semantic retrieval under a shared selection rule.
3. It combines a read-only curated base with run-scoped online knowledge ingestion and uses a fixed retrieval-confidence heuristic to trigger a prompt-directed web-augmentation policy when the available evidence is insufficient.
4. It provides an ablation-ready inference framework for varying these mechanisms, together with item-level output fields for terminal RAG status, confidence, retrieval attempt, serving endpoint, retrieved-context use, and observed web-search and ingestion activity. These fields summarize execution but do not constitute a complete retrieval trace.

The remainder of the paper relates MIRAGE-CARMA to multimodal agricultural question answering and adaptive RAG, describes its evidence-acquisition and response-generation pipelines, and specifies the planned benchmark and ablation protocol.
